# Generator is the tracker: volume contents

Data, models, checkpoints and results of the generative-tracking project (ICLR 2027 paper
"The Generator Is the Tracker"). Code lives in the Git repository; this volume holds everything
too large for Git. Written 2026-11-19; sizes are from that day and exclude raw image frames.

Folder names are deliberately left as they were during the runs. The names under `results/`
and `checkpoints/` are the run names used in the experiment log and in the paper's
run records (`paper/data/<run>`), and each LTX training config in the repository
(`video_generator/configs/<name>.yaml`) writes to `checkpoints/<name>` and `results/<name>`.
Renaming a folder here breaks that trail.

## Map to the repository areas

| Folder | Size | Repository area | Contents |
|---|---|---|---|
| `dancetrack/` | frames | datasets | DanceTrack `train1`, `train2` (40 videos), `val` (25), `test1`, `test2` (35) |
| `sportsmot/` | frames | datasets | SportsMOT `train`, `val` (45 each) and split lists |
| `pseudo_masks/` | 0.6 GB | datasets | SAM 3 silhouette labels, train splits only (`dancetrack/`, `sportsmot/`) |
| `ltx_ds/` | 36 GB | video generator | Prepared clips: `phase2_train`, `phase2_val`, `sportsmot_phase2_*` (training pairs), `fullseq` (validation and test windows), `phase1`, `longtest` |
| `models/ltx2_native/` | 71 GB | video generator | LTX-2.3 weights and text encoder used by every paper run |
| `models/cosmos3_nano_hf_records/` | small | image generators | Model card, configs and download records of the deleted Cosmos3-Nano base model |
| `checkpoints/ltx_*` | 17 GB | video generator | LoRA checkpoints and generated windows of the LTX runs |
| `checkpoints/p0_*`, `checkpoints/p1_*` | 14 MB | image generators | Run records of the Cosmos LoRA trainings of June 2026 (`train_log.json`, `sample_step*/`); the weights were deleted |
| `results/ltx_*` | small | video generator | Metrics and event files of the LTX runs. The full-scale evaluation runs are mirrored in `paper/data/`; the development-video records (`ltx_fullseq_dancetrack0065`, `ltx_chain_0065*`, `ltx_lengthtest_0065_L121`, `ltx_track_eval_step1500`, `ltx_hota_eval_step1500`) exist only here |
| `results/` (other) | small | image generators, datasets | Probe outputs of the Gemini image API, Cosmos, MOT17 and SAM 3 trials |

## Checkpoints behind the paper

| Paper name | Folder |
|---|---|
| Translation-only checkpoint (phase A, step 1,500) | `checkpoints/ltx_v2v_ic_lora_phase2` |
| Prefix-trained checkpoint (phase B, step 2,500) | `checkpoints/ltx_v2v_ic_lora_phase3` |
| SportsMOT phase A and phase B | `checkpoints/ltx_v2v_ic_lora_sm_phase2`, `checkpoints/ltx_v2v_ic_lora_sm_phase3` |
| Factorial cells A, B, C, D (generated windows) | `checkpoints/ltx_arm_a_chain`, `ltx_arm_b_indep`, `ltx_arm_c_chain_ckptA`, `ltx_arm_d_indep_ckptB` |
| Seeds 1 and 2 | `checkpoints/ltx_seed1_chain`, `checkpoints/ltx_seed2_chain` |
| Test-server submission | `checkpoints/ltx_test_chain`, `results/ltx_test_submission` |

Validation and test data never entered training: `pseudo_masks/` covers train splits only.

the repository owner's local records). None is read by a paper number.
